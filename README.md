# 💬 Comment Category Classifier

A Machine Learning web application that predicts the category of online comments using Natural Language Processing.

---



## Features

- Predict comment category
- Text preprocessing
- Prediction confidence
- Probability visualization
- Interactive Streamlit interface
- Dark theme

---

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Logistic Regression
- TF-IDF
- Pandas
- Matplotlib

---

## Categories

- 🟢 Neutral
- 🟡 Identity
- 🔴 Toxic
- ⚫ Violent

---

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
